**Context.** The docs follow the Headroom docs layout: a Fumadocs site with a **Docs** tab for people using the system and an **Engineering** tab that renders the repo's `docs/` folder (design spec, flows, requirements, plans). The scaffold already exists in `docs-site/`, aligned with the Headroom docs site's working Fumadocs 16 setup (versions, imports, "Copy Markdown" / "Open" page actions, `llms.txt` routes), but it hasn't been built yet, so this task makes it build and deploy.

**Implementation**

1. In `docs-site/`: `pnpm install`, then pin the installed versions of `fumadocs-core`, `fumadocs-ui`, `fumadocs-mdx`, `next`, `tailwindcss` (exact versions in the lockfile commit).
2. Fix imports for the installed Fumadocs major version if they differ: `RootProvider` (`fumadocs-ui/provider` or `fumadocs-ui/provider/next`), `createFromSource` static search, `defineDocs` options.
3. Check both tabs:
   - **Docs** (`content/docs/`): full sidebar from the `meta.json` files, 56 pages, four of them written (Introduction, How Detection Works overview, CI/CD flow diagrams, Glossary), the rest stubs with a "Planned for M#" callout and spec links.
   - **Engineering** (`content/engineering/`, generated by `scripts/sync-engineering.mjs` from `docs/`, gitignored): `architecture.md`, ingestion flows, writing guide, agents, development setup, feature requirements, requirements, plans.
4. Mermaid: ```` ```mermaid ```` blocks become `<Mermaid>` through `lib/remark-mermaid.mjs`; diagrams follow the light/dark theme.
5. Add `docs-site` to the root `pnpm-workspace.yaml` and the Makefile (`make docs`, `make docs-build`).
6. GitHub Pages: enable Pages (source: GitHub Actions); `.github/workflows/docs.yml` runs `pnpm check:mermaid` and `pnpm build`, and deploys `out/` on `main`. Pin actions by commit SHA (same rule as M0-04).
7. Add an offline internal-link check on `out/` (e.g. lychee with `--root-dir`).

**Out of scope.** Writing the stub pages (each milestone writes its own; see the "Docs to ship" column in the plan), API reference generation (M1 with `fumadocs-openapi`), "Copy Markdown" page actions (optional, later).

**Acceptance criteria**

- [ ] `pnpm build` produces `out/` containing every sidebar page of both tabs.
- [ ] Engineering tab renders `docs/architecture.md` with all its diagrams and working section anchors (e.g. `/engineering/architecture#34-flaky-occurrence`).
- [ ] `pnpm check:mermaid` passes; a deliberately broken diagram fails it.
- [ ] Search finds pages in the Docs tab.
- [ ] The docs workflow deploys to GitHub Pages on `main`, and the link check fails on a broken internal link.
