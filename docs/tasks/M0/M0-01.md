**Context.** Every later task assumes this layout, these tools and these commands. Getting them right once saves every agent from guessing.

**Implementation**

1. Create the GitHub repo `quarantine-tests` from the existing local folder, keeping its `.claude/` agents, skills and commands
2. Create the folders from §16 plus `ci/fq-cli/`, each with a short `README.md` saying what lives there:
   - `backend/`, `plugins/pytest-flaky-reporter/`, `plugins/playwright-flaky-reporter/`, `plugins/jest-flaky-reporter/`
   - `ci/fq-cli/`, `ci/jenkins-shared-library/vars/`, `ci/actions/`, `.github/workflows/`
   - `grafana/provisioning/{datasources,dashboards}/`, `deploy/helm/flaky-quarantine/`, `config-example/`, `demo/`, `ui/`, `docs/` (copy in `architecture.md`)
3. Root `pyproject.toml` as a `uv` workspace with members `backend`, `plugins/pytest-flaky-reporter`, `ci/fq-cli`. Each member gets its own `pyproject.toml` and an empty package that imports.
4. Root `package.json` + `pnpm-workspace.yaml` with members `plugins/playwright-flaky-reporter`, `plugins/jest-flaky-reporter`, `ui`. Each gets a `package.json` and `tsconfig.json` extending a root `tsconfig.base.json` (`strict: true`, `target: ES2022`, `module: NodeNext`).
5. Tooling config at the root:
   - `ruff` in `pyproject.toml`: line length 100, rule sets `E,F,I,UP,B,SIM,RUF`
   - `mypy.ini`: strict for `backend/app/domain` and `backend/app/config`
   - `.eslintrc` / `eslint.config.js` + `.prettierrc`
   - `.editorconfig`, `.gitignore` (Python, Node, `.env`, coverage, Playwright reports), `.gitattributes`
6. `.pre-commit-config.yaml` with hooks: ruff (check + format), mypy, prettier, eslint, end-of-file-fixer, trailing-whitespace, check-yaml, detect-private-key.
7. `Makefile` with the commands every task uses: `make setup` (uv sync + pnpm install + pre-commit install), `make lint`, `make typecheck`, `make test`, `make up`, `make down` (the last two are filled in by M0-05).
8. `CODEOWNERS` with your user as owner of every top-level folder, and `config-example/quarantine-policy.yaml` owned by QA (you, for now).
9. `README.md`: one paragraph on what the project is, a link to `docs/architecture.md`, and the `make` commands.

**Out of scope.** CI workflows (M0-04), docker-compose (M0-05), any application code.

**Acceptance criteria**

- [ ] Folder layout matches §16 plus `ci/fq-cli/`.
- [ ] On a clean clone, `make setup && make lint && make typecheck && make test` passes (tests may be one placeholder per package).
- [ ] `pre-commit run --all-files` passes.
- [ ] Every top-level folder has an owner in `CODEOWNERS`.

**Tests.** One placeholder test per Python and Node package that imports the package, so `make test` proves the workspace wiring.
