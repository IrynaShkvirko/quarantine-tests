**Context.** Every backend and Grafana task needs the same Postgres, Grafana and service containers, started with one command. Agents run integration tests against it.

**Implementation**

1. `backend/Dockerfile`: multi-stage. Builder stage on `python:3.12-slim` with `uv` installs dependencies from `uv.lock` into `/app/.venv`; runtime stage copies the venv and `backend/`, runs as a non-root user, `HEALTHCHECK` on `/healthz`. One image, three entrypoints: `api` (uvicorn), `worker` (procrastinate worker), `job <name>` (cron jobs).
2. `docker-compose.yml` at the root with services:
   - **db:** `postgres:16`, volume `pgdata`, healthcheck `pg_isready`, init script creating databases `fq` and `fq_test` and a read-only role `grafana_ro`.
   - **migrate:** backend image running `alembic upgrade head`, runs once, `depends_on: db (healthy)`.
   - **api:** backend image, port 8000, `depends_on: migrate (completed)`, source mounted with `--reload` in dev.
   - **worker:** backend image running the Procrastinate worker.
   - **grafana:** `grafana/grafana-oss`, port 3000, admin login from `.env`, `./grafana/provisioning` mounted; a provisioned Postgres datasource `fq-postgres` using `grafana_ro`.
3. `.env.example` with every variable and a comment: `FQ_DATABASE_URL`, `FQ_LOG_LEVEL`, `FQ_ENV`, `GRAFANA_ADMIN_USER`, `GRAFANA_ADMIN_PASSWORD`, placeholders for later (`FQ_GITHUB_APP_ID`, `FQ_JIRA_BASE_URL`, `FQ_SLACK_BOT_TOKEN`). `.env` is gitignored.
4. Makefile targets: `make up` (build + start, waits for api health), `make down`, `make reset-db` (drop volume, re-migrate), `make logs`, `make psql`.
5. Until M0-06 lands, the api can be a minimal FastAPI app with only `/healthz`, so this task is testable on its own.

**Out of scope.** Jenkins container (M5-04), Kubernetes (M6).

**Acceptance criteria**

- [ ] On a clean clone with `.env` copied from `.env.example`, `make up` ends with `/healthz` returning 200.
- [ ] Grafana opens at `localhost:3000` and the `fq-postgres` datasource tests OK.
- [ ] `grafana_ro` can `SELECT` but not `INSERT` (checked in a test or script).
- [ ] `make reset-db` gives an empty, migrated database.
- [ ] The backend image runs as a non-root user and is under 300 MB.
